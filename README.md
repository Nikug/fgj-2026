## About

Skeittipeli is a 3D skateboarding game built with Godot Engine 4.6 featuring physics-based gameplay.

---

## 🛹 Requirements
- Godot Engine 4.6 or higher
- Windows OS (configured for DirectX 12)
- Jolt Physics Engine (pre-configured)

---

## 📦 Installation

1. Download and install [Godot Engine 4.6](https://godotengine.org/download)
2. Clone or download this repository
3. Open Godot Engine
4. Click "Import" and navigate to `skeittipeli/project.godot`
5. Click "Import & Edit"

---

## 🚀 How to Run

Once the project is imported in Godot:
- Press **F5** or click the "Run Project" button
- Use the main menu to start the game

## 🔧 Troubleshooting
- **Project won't import:** Ensure you're using Godot 4.6 or newer
- **Physics errors:** Jolt Physics is configured - check addons folder
- **Rendering issues:** DirectX 12 is required on Windows
